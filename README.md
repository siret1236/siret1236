# SIRET1236 — Luxury Beauty & Cosmetics

**Where Beauty Meets Elegance.**

A responsive, multi-page, luxury-inspired beauty storefront demo built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Home and featured products
- `shop.html` — Searchable, filterable, sortable product catalog
- `about.html` — Brand story
- `journal.html` — Beauty editorial
- `contact.html` — Demo contact form
- `faq.html` — Frequently asked questions
- `shipping.html` — Shipping and returns placeholder
- `privacy.html` — Privacy notice template
- `terms.html` — Terms template

## Assets
- `assets/css/style.css` — Layout and responsive styles
- `assets/js/products.js` — Demo product data
- `assets/js/app.js` — Catalog, cart, navigation, and demo forms

## Run locally
Open `index.html` in your browser. Internet access is needed for externally hosted Unsplash photography and Google Fonts.

## Publish with GitHub Pages
Upload the **contents** of this folder to a GitHub repository root. In Settings → Pages choose Deploy from a branch → `main` → `/ (root)`. Avoid mixing this storefront into the special GitHub profile README repository if you want to keep your profile separate.

## Before going live
This is a **demo**, not a functioning business checkout. Product names, photos, and prices are illustrative; there is no verified inventory, backend, checkout, payment, shipping, real newsletter registration, or message delivery. Replace demo data, verify image usage rights, add secure commerce services, and obtain legal review of policies before selling products.

Brand palette: pastel pink `#F5D6DC`, champagne gold `#C9A46A`, white `#FFFFFF`.
